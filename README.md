### [Office Language Doctor](https://github.com/Nfreakz/office-language-doctor)

A privacy-first browser tool to audit and repair proofing-language metadata in Word, PowerPoint, OpenDocument and RTF files. Files stay in your browser: no upload, backend or account required.

The **0.5.0 Community Edition** supports 17 document formats, conservative Smart Fix, Catalan and Valencian review, and local diagnostic exports. It repairs language metadata without rewriting your document's text.
